# Project Specification

## Objective

Build a production-grade authentication system while learning PostgreSQL, NestJS, backend architecture, sessions, authorization, and Next.js BFF.

## Roles

```text
ADMIN
USER
```

## Core Features

- Registration
- Login
- Logout
- Server-side sessions
- Session expiration
- Authentication guards
- Role-based authorization
- Next.js BFF
- Secure HttpOnly cookie
- Security review

## Constraints

- PostgreSQL
- Raw SQL + `pg`
- NestJS
- Next.js BFF
- No Prisma yet
