# Glossary

## Migration
A versioned SQL change applied to the database.

## Checksum
A hash used to detect whether an executed migration file was modified.

## Advisory Lock
A PostgreSQL application-controlled lock associated with a database session.

## BFF
Backend-for-Frontend: a server-side layer between browser and backend API.

## Session
Server-side authentication state associated with a client.

## Authentication
Verifying who a user is.

## Authorization
Determining what an authenticated user is allowed to do.
